# V2.5 二维标量有限差分模式求解增强版

## 一、版本定位

V2.5 是二维标量有限差分模式求解增强版，是 V2.6 工程整理和后续开发所继承的基础稳定版本。

## 二、主要新增功能

- 将近似高斯模式场升级为二维标量有限差分模式求解。
- 实现 `solve_scalar_fd_mode()`。
- 根据 SOI 波导截面构建折射率分布 `n(x,y)`。
- 离散标量 Helmholtz 方程并求解本征值 `β²`。
- 提取 `neff = β / k0`。
- 生成有限差分 `mode_profile.png` 和 `neff_vs_width.png`。
- 在 `mode_result.json` 中记录 `beta`、`beta_sq`、网格尺寸及步长。
- 将有限差分 `neff` 接入 MMI 优化和波长扫描。
- 修正波长扫描与有限差分 `neff` 不一致的问题。

## 三、主要输出结果

`index_profile.png`、`mode_profile.png`、`mode_result.json`、`neff_vs_width.png`、MMI 优化图、波长扫描图、GDS 和中文报告。

## 四、局限性

- 当前仍是二维标量有限差分近似。
- 不是严格全矢量 FDE、FEM、EME 或 FDTD。
- MMI 响应模型仍是轻量 surrogate model。
- 尚未实现 MMI 区域真实传播仿真。

## 五、与下一版本的关系

V2.6 不重写 V2.5 核心算法，重点完成工程结构清理、文档封版、输出管理和 GitHub 版本管理规范化。
