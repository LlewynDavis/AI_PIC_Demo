# V2.1 Streamlit 网页展示增强版

## 一、版本定位

V2.1 是 Streamlit 网页展示增强版，重点提升网页端结果展示、最新结果加载和文件下载能力。

## 二、主要新增功能

- 新增 `core/v2_web_utils.py`。
- 网页展示 `mode_profile.png`、`neff_vs_width.png` 和 `mode_result.json` 关键指标。
- 网页展示 MMI 优化、`length_sweep.png`、`width_length_heatmap.png` 和 `layout_preview.png`。
- 支持报告、GDS、ZIP 和 `mode_result.json` 下载。
- 支持加载最近一次运行结果。

## 三、主要输出结果

延续 V2 的模式与优化文件，并在网页中集中展示模式、曲线、版图、报告和下载入口。

## 四、局限性

- 该版本主要增强展示层。
- 底层物理模型与 V2 基本一致。
- 尚未加入波长扫描。

## 五、与下一版本的关系

V2.3 在网页展示基础上加入波长扫描和带宽趋势分析。
