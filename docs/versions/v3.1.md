# V3.1 传播仿真校准与模型对比版

## 一、版本定位

V3.1 在 V3.0 二维标量 BPM 传播仿真基础上，增加输出窗口宽度敏感性分析、增强传播图显示以及 surrogate model 与 BPM model 的结果对比，用于提高传播仿真结果的可解释性和工程可信度。

## 二、主要新增功能

- 输出窗口宽度敏感性分析。
- 增强版传播图 `field_propagation_enhanced.png`。
- 输出窗口敏感性图 `output_window_sensitivity.png`。
- 输出窗口敏感性结果 `output_window_sensitivity_result.json`。
- Surrogate model 与 BPM model 对比。
- `model_comparison.png`。
- `model_comparison_result.json`。
- 报告和网页新增 V3.1 分析内容。
- 完整性检查更新。

## 三、主要输出结果

- `field_propagation_enhanced.png`
- `output_window_sensitivity.png`
- `output_window_sensitivity_result.json`
- `model_comparison.png`
- `model_comparison_result.json`

## 四、局限性

- 仍然是二维标量 BPM 近似。
- 输出功率仍然来自窗口积分。
- `window_based_insertion_loss_db` 不能等同于严格器件插入损耗。
- Surrogate model 和 BPM model 不是完全相同物理层级的模型。
- 该版本尚未实现严格 S 参数提取。

## 五、与下一版本的关系

V3.1 为 V3.5 宽带 S 参数趋势分析打基础。后续可基于不同波长下的传播结果，进一步分析 S21、S31、imbalance 和等效带宽趋势。
