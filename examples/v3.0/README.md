# V3.0 代表性传播仿真结果

此目录用于保存 AI_PIC_Demo V3.0 的少量代表性传播仿真结果，适合汇报、展示和复现。

建议保存：

- `propagation_result.json`
- `field_propagation.png`
- `field_output_profile.png`
- `report.md`

请从已验证的 `outputs/run_*` 中人工挑选结果，不要自动复制全部运行目录、大量 ZIP、缓存或临时文件。

> 模型说明：V3.0 使用二维标量 BPM 近似，不是严格全矢量 FDTD/FEM/EME 仿真；输出功率采用简化端口窗口积分估算。
