# V3.2 端口模式重叠积分版

## 一、版本定位

V3.2 在 V3.1 传播仿真校准基础上，引入简化 Gaussian 输出端口模式，将二维标量 BPM 输出场投影到输出端口模式上，用于获得比简单窗口积分更合理的端口功率估计。

## 二、主要新增功能

- 新增端口 Gaussian mode 构建；
- 新增 BPM 输出场与端口模式的 overlap integral；
- 新增 `overlap_p_out1`、`overlap_p_out2`、`total_overlap_power`；
- 新增 `overlap_based_insertion_loss_db`；
- 新增 `mode_overlap_result.json`；
- 新增 `mode_overlap_comparison.png`；
- 新增 `field_output_profile_with_modes.png`；
- 报告和网页新增 V3.2 分析内容；
- 完整性检查更新。

## 三、主要输出结果

- `bpm_final_field_data.npz`
- `mode_overlap_result.json`
- `mode_overlap_comparison.png`
- `field_output_profile_with_modes.png`

## 四、局限性

- 端口模式为 Gaussian 近似；
- BPM 场为二维标量近似；
- overlap-based power 仍不是严格全矢量本征模式功率；
- 当前尚未实现严格 S 参数提取。

## 五、与下一版本的关系

V3.2 为后续 V3.5 宽带 S 参数趋势分析提供更合理的端口功率提取方法。后续可在不同波长下执行 mode overlap，从而得到等效 S21、S31 和带宽趋势。
