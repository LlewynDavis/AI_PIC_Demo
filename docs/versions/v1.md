# V1 物理建模增强版

## 一、版本定位

V1 是物理建模增强版，完成 SOI 材料参数、简化有效折射率估算、MMI 宽度—长度二维扫描、GDS 生成和网页展示。

## 二、主要新增功能

- 建立 SOI 材料参数库。
- 增加简化有效折射率 `neff` 估算。
- 增加 MMI 宽度—长度二维联合扫描。
- 生成 `width_length_heatmap.png` 二维优化热力图。
- 根据最优参数生成 GDS 和版图预览。
- 增加 Streamlit 网页展示与中文报告生成。

## 三、主要输出结果

结构化设计参数、SOI 物理参数、MMI 优化结果、二维热力图、GDS、版图预览、中文报告和结果包。

## 四、局限性

- `neff` 仍是简化估算。
- MMI 响应模型是轻量 surrogate model。
- 尚未引入波导模式场求解。

## 五、与下一版本的关系

V1.5 在 V1 物理流程基础上增强参数校验、运行目录隔离、日志记录和结果完整性检查。
