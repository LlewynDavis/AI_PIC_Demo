# V3.3：DesignSpec 与本地 MCP 基础版

## 版本定位

V3.3 为 AI_PIC_Demo 建立统一的结构化设计规格、需求澄清、阶段状态、评测和本地工具调用基础，同时保持 V3.2 物理算法与基准结果不变。

## 新增功能

- PIC DesignSpec 1.0 与 JSON/YAML 示例。
- Pydantic 类型、单位、范围、求解器和流程依赖校验。
- 参数来源 `user/default/formula/optimizer/unverified`。
- `ready/needs_clarification/invalid` 需求状态。
- `run_manifest.json`、`status.json` 和阶段错误码。
- 本地 MCP Server/Client：
  - `validate_design_spec`
  - `estimate_mmi_geometry`
  - `inspect_latest_run`
- 30 条需求 Prompt Benchmark 和自动测试。

## 主要输出

- `design_spec.json`
- `run_manifest.json`
- `status.json`
- `benchmarks/v3.3/benchmark_result.json`
- V3.2 原有模式、优化、BPM、overlap、GDS 和报告输出。

## 局限性

V3.3 不修改二维标量有限差分模式求解、MMI surrogate 优化、二维标量 BPM、Gaussian 端口模式或 overlap 计算。结果不是严格全矢量 FDE/FDTD/FEM/EME、完整 S 参数或流片签核结论。

## 与下一版本的关系

后续数值一致性、网格收敛、BPM 能量收支和 overlap 校准必须在独立批准任务中实施，不能借 V3.3 静默修改物理模型。
