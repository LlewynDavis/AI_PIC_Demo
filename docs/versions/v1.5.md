# V1.5 工程稳定版

## 一、版本定位

V1.5 是工程稳定版，重点增强运行目录、参数校验、日志记录和输出完整性检查。

## 二、主要新增功能

- 使用 `core/validation.py` 执行参数合法性检查。
- 使用 `core/run_manager.py` 管理时间戳运行目录。
- 建立 `outputs/run_时间戳/` 输出机制。
- 生成 `run_log.txt` 运行日志。
- 使用 `tools/check_latest_run.py` 检查结果完整性。
- 在报告中加入工程稳定版说明并完善结果打包。

## 三、主要输出结果

独立运行目录、参数文件、运行日志、优化结果、GDS、报告和完整结果 ZIP。

## 四、局限性

- 物理模型仍以简化有效折射率估算为主。
- 尚未真正求解波导模式。

## 五、与下一版本的关系

V2 在 V1.5 的工程基础上引入模式求解流程，并将模式分析结果接入 MMI 优化和报告。
