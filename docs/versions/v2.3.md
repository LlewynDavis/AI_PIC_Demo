# V2.3 波长扫描与带宽趋势分析版

## 一、版本定位

V2.3 在固定最优 MMI 参数下分析波长变化对分光性能的影响，是波长扫描与带宽趋势分析版本。

## 二、主要新增功能

- 新增 `core/wavelength_sweep.py`。
- 扫描 1.50–1.60 μm 波长范围。
- 生成 `wavelength_sweep.png`。
- 生成 `wavelength_imbalance.png`。
- 生成 `wavelength_sweep_result.json`。
- 在报告和网页中新增波长扫描与带宽趋势分析区域。

## 三、主要输出结果

输出功率随波长变化曲线、分光不均衡曲线、结构化波长扫描结果，以及包含带宽趋势分析的网页和报告。

## 四、局限性

- 初始波长扫描使用旧 `neff` 经验公式。
- 该结果与后续有限差分 `neff` 存在不一致。
- MMI 响应仍使用轻量 surrogate model。

## 五、与下一版本的关系

V2.5 将模式求解升级为二维标量有限差分形式，并修正波长扫描与有限差分 `neff` 不一致的问题。
