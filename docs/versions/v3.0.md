# V3.0 MMI 区域二维光场传播仿真版

## 一、版本定位

V3.0 在 V2.6 工程稳定版本基础上，新增 MMI 区域二维标量 BPM 光场传播仿真，用于观察光场在 MMI 器件内部的演化过程，并基于输出端口区域积分估算分光性能。

## 二、主要新增功能

- 新增 `core/propagation_solver.py`。
- 构建 MMI 横向传播网格和等效折射率分布。
- 构建功率归一化 Gaussian 输入光场。
- 使用二维标量 split-step Fourier BPM 近似传播。
- 生成 `field_propagation.png`。
- 生成 `field_output_profile.png`。
- 生成 `propagation_result.json`。
- 网页端展示传播仿真结果。
- 报告中追加传播仿真分析章节。

## 三、主要输出结果

- `propagation_result.json`
- `field_propagation.png`
- `field_output_profile.png`

## 四、局限性

- 当前方法是二维标量 BPM 近似。
- 不是严格全矢量 FDTD/FEM/EME。
- 端口功率由窗口积分估算。
- MMI 传播边界和输出端口建模仍较简化。

## 五、与下一版本的关系

V3.0 为后续 V3.5 宽带 S 参数趋势分析和 V4.0 PDK/DRC 工艺检查提供传播仿真基础。后续可进一步提高传播求解精度，或接入 Lumerical、COMSOL 等外部仿真工具。
