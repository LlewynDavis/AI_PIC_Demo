# AI_PIC_Demo 工程路线

## 当前阶段

V3.3 建立 PIC DesignSpec、确定性需求解析、结构化校验、阶段状态、Prompt Benchmark 和最小本地 MCP 工具层。该阶段的目标是让输入、运行和错误可以复现与审计，不改变 V3.2 物理模型。

## 后续路线

### V3.4：数值一致性与校准

- 统一单点模式求解和 `neff_vs_width` 的网格与跨度策略。
- 增加网格收敛、BPM 能量收支和边界吸收诊断。
- 增加端口模式宽度敏感性分析。

### V3.5：Overlap 驱动的稳健优化

- surrogate 粗筛、BPM/overlap 复核和候选重排序。
- 波长、宽度、长度与制造偏差容差分析。
- 输出名义、最差和统计指标。

### V3.6：可复现产品化工作台

- CI、跨平台安装、运行缓存、进度与失败阶段展示。
- 结果对比、模型来源和可信度标签。
- 可选 GPT 澄清助手必须通过 DesignSpec Schema，并保留无密钥确定性回退。

### V4：高保真外部适配

- 接入真实端口本征模或外部 FDE/FDTD/FEM/EME 适配器。
- 建立低、中、高精度证据链后再讨论严格复数幅度或 S 参数。

## 长期研究方向

RAG、多 Agent、扩展器件库、扩展 PDK 和自动微调属于长期研究方向。本路线只记录方向，不代表当前已经实现或验证。任何私有 PDK、代工厂保密规则、未公开实验数据和密钥配置都不得进入公开仓库。
