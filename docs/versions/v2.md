# V2 模式求解版

## 一、版本定位

V2 是模式求解版，开始把波导模式分析结果接入 MMI 优化流程。

## 二、主要新增功能

- 增强 `core/mode_solver.py`。
- 生成近似 TE0 模式场 `mode_profile.png`。
- 生成 `neff_vs_width.png`。
- 生成结构化结果 `mode_result.json`。
- 将模式模块输出的 `neff` 接入 MMI 二维优化。
- 在报告中新增模式求解分析章节。

## 三、主要输出结果

近似模式场图、有效折射率宽度扫描图、结构化模式结果和包含模式分析的中文报告。

## 四、局限性

- 模式场仍是近似模型。
- 不是严格有限差分或全矢量模式求解。
- MMI 区域传播仍未真实仿真。

## 五、与下一版本的关系

V2.1 重点增强 Streamlit 网页展示和下载能力，使模式求解结果能够在网页端完整查看。
